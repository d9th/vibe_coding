# React アナログ時計アプリケーション

TDD（テスト駆動開発）手法で実装したReactアナログ時計アプリケーションです。

## 特徴

- リアルタイムで現在時刻を表示するアナログ時計
- 時針、分針、秒針の正確な角度計算
- 時間マーカーと数字の表示
- レスポンシブなデザイン
- TDD手法による開発（10個のテストケース、すべて合格）

## 技術スタック

- React 18
- Vite
- Vitest
- React Testing Library
- Tailwind CSS

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# テストの実行
npm test

# ビルド
npm run build
```

## TDD開発プロセス

1. **Red**: テストを先に作成（失敗することを確認）
2. **Green**: テストが通るように実装
3. **Refactor**: コードの品質とスタイリングを改善

すべてのテストが合格し、アナログ時計が正しく動作します。
